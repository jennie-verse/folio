# folio — 사용 방법

화면에 나오는 메뉴 이름은 **영문**입니다. 아래에 한국어 설명과 함께 적었습니다.

---

## 1. 문서 넣기

1. 아래쪽 **가져오기(Import files)** 를 누릅니다.
2. Files·iCloud Drive에서 파일을 여러 개 고를 수 있습니다.
3. iPad에서는 다른 앱에서 파일을 끌어다 놓아도 됩니다.

넣고 나면 `Added 3 documents.` 같은 안내가 잠깐 뜹니다.

- 같은 파일을 다시 넣으면 복사본이 생기지 않고 원래 문서에 다시 연결됩니다 —
  `Already in folio — reconnected instead.`
- 열 수 없는 파일은 이유와 함께 목록으로 보여 줍니다.
- 한글 파일명은 그대로 표시·검색됩니다.

### 파일 없이 글·코드를 붙여넣어 넣기 (Paste code)

파일이 없어도, 복사해 둔 글이나 코드를 바로 문서로 만들 수 있습니다.

1. 아래쪽 **`Paste code`**(또는 문서가 하나도 없을 때 나오는 같은 이름의 버튼)를 누릅니다.
   `Add from text` 창이 열리고 글 입력칸에 바로 커서가 놓입니다.
2. 글이나 코드를 붙여넣거나 직접 입력합니다. **`Paste from clipboard`**를 누르면 복사해 둔
   내용이 한 번에 들어옵니다(iPhone은 처음에 붙여넣기 허용 확인이 뜰 수 있습니다. 안 되면
   입력칸을 길게 눌러 `Paste`를 고르세요).
3. **종류(Type)** 는 `Markdown` · `Text` · `HTML` · `CSV` 중에서 고릅니다. HTML 코드
   (`<!doctype html>`이나 `<div>…</div>`처럼 시작하는 글)를 붙여넣으면 **자동으로 `HTML`이
   선택**되고, 그 밖에는 마지막에 쓴 종류(처음에는 `Markdown`)가 선택됩니다. 직접 누르면
   그 선택이 우선합니다.
4. **제목**은 비워 두면 내용에서 자동으로 가져옵니다 — HTML은 `<title>`(없으면 첫 `<h1>`),
   Markdown은 YAML 머리말의 `title:` 또는 첫 제목(`# …`), 그 밖에는 첫 줄입니다.
   직접 적으면 그대로 제목이 됩니다.
5. **`Folder`** 는 지금 열려 있는 폴더가 미리 선택되어 있고, `Unsorted`나 다른 폴더로 바꿀 수 있습니다.
6. **`Add to library`** 를 누르면 파일을 가져온 것과 똑같이 저장됩니다(검색·백업·재연결 모두 동일).
   `Added “제목”.` 안내에 뜨는 **`Open`** 을 누르면 바로 열립니다.

- 입력한 내용은 창을 닫아도(바깥을 실수로 눌러도) 앱을 끄기 전까지 **임시로 남아** 다시 열면 그대로
  복원됩니다. 문서로 추가하고 나면 지워집니다. 어디에도 저장·전송되지 않습니다.
- 똑같은 내용을 다시 넣으면 `That exact text is already in folio.` 라고 알려 주고 복사본을 만들지 않습니다.
- `Add to library`는 글이 비어 있으면 눌러지지 않습니다. 키보드가 열려도 가려지지 않도록
  `Add to library`/`Cancel` 버튼은 창 **맨 위**에 있습니다.
- PDF·이미지·ZIP은 글로 입력할 수 없으므로 종류에 없습니다(`Import files`로 넣으세요).

## 2. 첫 화면(Library)

| 요소 | 뜻 |
|---|---|
| 검색창 **Search documents** | 제목·파일명·태그·본문을 한 번에 찾습니다 |
| **⋯ Library** | `Sort` · `Custom order…` · `Filter by type` · `Filter by tag` · `Folders` · `My highlights and notes`를 모아 놓은 메뉴 |
| **☑ Select** | 여러 문서를 골라 한꺼번에 폴더로 옮기기·삭제·주석 Markdown 내보내기 |
| **Continue** 줄 | 최근에 보던 문서 3건. 가는 선이 어디까지 읽었는지 보여 줍니다 |
| 폴더 탭 | `All` `Unsorted` 그리고 만든 폴더들. 폴더마다 **다른 파스텔색**이라 탭과 문서 줄의 폴더 배지를 한눈에 구분합니다. 맨 끝 점선 칩 **`+ New folder`** 로 새 폴더를 만듭니다 |
| 폴더 바 | 폴더를 열면 탭 아래에 그 폴더 이름과 **`Rename`** · **`Delete`** 가 나타납니다 |
| 상태 칩 | `All` `Pinned` `Needs file` `Recent` |
| `Showing 3 of 12` 줄 | 상태 칩·`Filter by type`·`Filter by tag`·검색어 때문에 목록이 줄어 있을 때만 나타나고, **`Clear filters`** 로 한 번에 모두 풉니다 |
| 아래쪽 **`Import files`** · **`Paste code`** | 파일을 가져오거나 글·코드를 붙여넣어 문서로 만듭니다 |

### 폴더·태그로 정리하기

- 문서 줄을 길게 누르면(또는 우클릭) 뜨는 시트의 **`Edit tags`**로 쉼표로 구분한
  태그를 자유롭게 답니다(예: `vocab, avgo`). 태그는 문서 줄 아래에
  `#vocab #avgo`처럼 작게 표시되고, 검색창에 태그 글자를 쳐도 바로 찾아집니다.
- **⋯ → `Filter by tag`**에서 실제로 쓰인 태그만 목록으로 뜨고, 여러 개를
  고르면 **그 태그를 전부 가진 문서만** 남습니다(AND 조건, `Filter by type`과
  같은 방식).
- **폴더 만들기**: 폴더 탭 줄 맨 끝의 **`+ New folder`** 를 누르고 이름을 적으면 폴더가 만들어지고
  **바로 열립니다**. 새 폴더는 항상 탭 줄의 **맨 끝**에 붙고, 만든 순서대로 서로 다른 색
  (주황 → 노랑 → 초록 → 하늘 → 보라)을 받습니다. 색은 이름을 바꿔도, 다른 폴더를 지워도 바뀌지 않습니다. `All`·`Unsorted`는 기본 탭 이름이라 폴더 이름으로 쓸 수 없습니다
  (`Pick another name — All and Unsorted are built-in tabs.` 안내가 뜹니다).
- **폴더 이름 바꾸기**: 폴더 탭을 눌러 열고, 탭 아래 폴더 바의 **`Rename`** 을 누릅니다.
  같은 이름(대소문자 무시)의 폴더가 이미 있으면 `That folder already exists.` 로 막습니다.
  **Sync를 켜 두었다면** 다른 기기에도 새 이름이 반영됩니다(다른 기기의 옛 이름 폴더는 남고, 문서만
  새 이름 폴더로 옮겨집니다).
- **폴더 지우기**: 폴더 바의 **`Delete`** → 확인 창에 이동할 문서 수가 표시됩니다. **폴더를 지워도 그 안의
  문서는 지워지지 않고 `Unsorted`로 이동**합니다.
- 폴더를 여러 개 한꺼번에 관리하려면 **⋯ → `Folders`** 를 엽니다(폴더별 `Rename`/`Delete`, `+ New folder`).
- **폴더가 열려 있을 때 `Import files`·`Paste code`·끌어다 놓기로 넣은 문서는 그 폴더에 저장**됩니다
  (`Added 2 documents to 업무.`). 폴더 없이 넣고 싶으면 `All`이나 `Unsorted` 탭에서 넣으세요.
  `Paste code` 창에서는 폴더를 직접 고를 수 있습니다.
- 문서를 폴더에 넣으려면 문서 줄을 길게 눌러(또는 우클릭) **`Move to folder`**를
  고릅니다. 현재 폴더가 있는 문서는 줄에 폴더 이름 배지가 뜹니다.
- 폴더·태그·폴더 색은 모두 **백업 파일에 포함**되어 `Restore from backup`으로 그대로
  복원됩니다(색 정보가 없는 예전 백업은 폴더 id에서 정해진 색으로 복원됩니다).
  Sync를 켜면 올라가는 것은 문서의 제목·태그·**폴더 이름**·날짜·크기뿐이며, 문서 본문과
  폴더 색은 올라가지 않습니다.

글자 크기를 6px·8px로 줄이면 Continue 줄은 자동으로 접히고 화면이 순수한
목록이 됩니다.

### 여러 문서 한꺼번에 다루기(Select)

1. Library 상단의 **☑ Select**를 누릅니다. 문서 줄마다 체크박스가 나타나고,
   탭하면 열기 대신 선택됩니다.
2. 아래 바에 선택 개수가 뜹니다. `Select all`은 **지금 목록에 보이는 문서**를
   모두 고르고, `Clear`는 선택을 비웁니다. 폴더 탭·검색·필터를 바꾸면 화면에서
   사라진 문서는 선택에서 자동으로 빠집니다(안 보이는 문서가 실수로 삭제되지 않게).
3. 선택한 문서에 쓸 수 있는 동작:
   - **`Move to folder`** — 폴더 목록(`Unsorted` 포함)에서 하나를 고르면 선택한
     문서가 모두 그 폴더로 옮겨집니다. 맞는 폴더가 없으면 `+ New folder…`로 바로
     만들어 넣을 수 있습니다.
   - **`Delete`** — 확인 창(`Delete N documents?`)에서 `Delete`를 누르면 지워지고,
     그 뒤 **5초 동안 `Undo`** 로 되돌릴 수 있습니다. 5초가 지나면 노트·하이라이트를
     포함해 완전히 삭제됩니다.
   - **`Export .md`** — 아래 "주석 묶어 내보내기" 참고.

#### 주석 묶어 내보내기(Export .md)

1. 원하는 만큼 고르면(**최대 50개, 합쳐서 5MB**) `Export .md`가 활성화됩니다.
2. `Export .md`를 누르면 순서를 정하는 화면이 열립니다. **기본
   순서는 제목 오름차순**이고, 각 문서의 `↑ Up`/`↓ Down`으로 순서를 바꿉니다.
3. `Export selected .md`(공유/다운로드) 또는 `Copy Markdown`(클립보드로 복사)
   중 고릅니다. 공유가 가능하면 Apple 공유 시트가 열리고, 안 되면 자동으로
   `.md` 파일 다운로드로 대체됩니다.
4. 결과는 **하나의 Markdown 파일**(`folio-notes-YYYY-MM-DD.md`)입니다. 문서마다
   `##` 제목으로 구분되고, 그 아래 하이라이트·메모가 기존 문서별 내보내기와
   같은 형식으로 들어갑니다. **주석이 하나도 없는 문서도 포함되며**, 그 자리에
   `_No annotations._`라고 표시됩니다 — 조용히 빠지지 않습니다.

> 기존 `Export .md`(주석 1건)와 `Export all .md`(문서 1개 전체)는 그대로 있습니다.
> `Select`는 **문서 여러 개를 한 번에** 묶을 때만 씁니다.

### 문서 줄 왼쪽의 세로선 (keep line)

색이 아니라 **굵기와 모양**으로 상태를 구분합니다.

| 선 | 뜻 |
|---|---|
| 굵은 실선 (3px) | 핀 지정 — 사본이 절대 사라지지 않습니다 |
| 가는 실선 (1px) | 사본이 이 기기에 있습니다 |
| 가는 점선 | **Needs file** — 사본이 해제되었습니다. 원본 파일이 필요합니다 |

만료가 3일 이하로 남으면 `3d` 같은 작은 표시가 붙습니다.

### 문서 줄을 길게 누르면

`Open`(열기) · `Pin`(핀) · `Rename`(제목 수정) · `Edit tags`(태그) ·
`Move to folder`(폴더로 이동) · `Export original`(원본 내보내기) · `Delete`(삭제)

### 정렬(Sort)과 사용자 지정 순서(Custom order)

`⋯ Library` → `Sort`에서 고릅니다: `Recently opened` · `Date added (newest/oldest)` ·
`Title A–Z / Z–A`(한글이 영문보다 먼저) · `Size (largest/smallest)` · `Type` · `Custom order`.
고정(Pin)한 문서는 `Title`과 `Custom order`를 제외한 모든 정렬에서 맨 위에 옵니다.

**Custom order(내 마음대로 순서)**

1. `⋯ Library` → `Custom order…`(또는 `Sort` → `Custom order`)를 엽니다.
2. 문서마다 `⤒`(맨 위로) · `↑` · `↓` 버튼으로 순서를 바꾸고 `Save order`를 누릅니다.
   저장하면 정렬이 자동으로 `Custom order`가 됩니다.
3. 폴더 탭을 고른 상태에서 열면 **그 폴더의 문서만** 정렬하고, 다른 폴더의 순서는
   그대로입니다. 새로 가져온 문서는 저장된 순서 위쪽(맨 위)에 나타납니다.
4. 순서는 이 기기에만 저장되며(Sync로 올라가지 않음) 백업 파일에는 포함됩니다.

## 3. 문서 보기(Viewer)

- **본문을 한 번 탭하면** 위아래 바가 함께 사라집니다. 다시 탭하면 돌아옵니다.
- 상단 바의 **`Aa` 버튼**(제목 옆)을 누르면 문서 시트가 열립니다. 제목을
  탭해도 같은 시트가 열립니다 — `Aa`는 이 화면에 눈에 보이는 버튼이 없다는
  지적에 따라 2026-09-11에 새로 추가된, 글자 크기·배경을 조정하는 자리라는
  것을 바로 알아볼 수 있는 진입점입니다.
- 이 시트의 `Text size`(문서 본문 글자 크기)로 조정하거나, 본문을 두 손가락
  으로 오므리거나 벌려도 됩니다. 문서 본문 글자 크기는 **문서마다 따로
  저장**되고, 설정(Settings)의 앱 글자 크기와는 별개입니다.
- TXT·Markdown·CSV 문서는 같은 시트에 **`Background`**(읽기 배경) 선택지도
  있습니다 — `Auto`(앱의 Light/Dark/System 설정을 그대로 따름), `Sepia`,
  `Mint`, `Sky`, `Lavender`, `Gray` 6가지. 앱 전체 테마와 별개로, 문서를
  읽는 동안의 배경·글자색만 이 값으로 바뀌며 **모든 문서에 공통 적용**되는
  설정입니다(문서마다 따로 저장되지 않음). PDF는 페이지가 이미 그림으로
  렌더링돼 있어 배경을 다시 칠할 수 없고, HTML 문서는 Read 모드가 원본
  디자인을 그대로 보존하도록 만들어졌기 때문에(자체 배경·글자색이 있는
  문서와 충돌할 수 있음) 이 선택지에서 제외됩니다.

### 선택·하이라이트·메모

- PDF의 실제 텍스트, TXT, Markdown, CSV, HTML(`Read`/`Run` 모드 포함) 등에서
  글자를 선택하면 Apple의 `Copy`, `Look Up` 같은 기본 메뉴를 그대로 사용할 수
  있습니다.
- 선택이 유지되는 동안 Folio 작업 막대에서 `Highlight`, `Add note`,
  `Export .md`, `Read aloud`를 선택할 수 있습니다.
- `Read aloud`는 선택한 문구를 기기의 음성 합성(Web Speech API, 인터넷 연결
  불필요)으로 읽어 줍니다. **한글, 영문, 숫자가 섞인 문장도 모두 읽을 수
  있습니다** — 문구를 한글 구간과 영문/숫자 구간으로 자동으로 나눠, 한글
  구간은 한국어 음성으로, 영문·숫자 구간은 영어 음성으로 순서대로 이어
  읽습니다(예: "현재 $364라는 주가에..." → "현재"는 한국어로, "$364"는
  영어로, "라는 주가에..."는 다시 한국어로). 재생 중에는 버튼이 `Stop`으로
  바뀌며, 다시 누르거나 다른 텍스트를 선택하거나 문서를 닫으면 재생이
  멈춥니다. 브라우저가 음성 합성을 지원하지 않으면 버튼이 표시되지 않습니다.
  기기에 설치된 한국어 음성이 없으면 한글 구간은 소리가 나지 않거나 다른
  음성으로 대체될 수 있습니다(iOS/iPadOS는 기본으로 한국어 음성을 포함).
- 상단의 `▧` 또는 제목 메뉴의 `Notes`에서 저장한 하이라이트와 메모를 보고,
  수정·삭제·개별 내보내기·문서 전체 Markdown 내보내기를 할 수 있습니다.
- 각 항목의 `Go to`를 누르면 시트가 닫히고 그 하이라이트·메모가 있던 정확한
  위치(PDF는 해당 페이지, 그 외 형식은 저장된 문구 위치)로 바로 이동합니다.
- 항목이 여러 개면 색상 칩(`Core` `Agree` `Question` `Word` `Quote`)으로
  걸러볼 수 있고, 각 항목 앞의 작은 점으로 하이라이트 색을 바로 알아볼 수
  있습니다.
- 선택하지 않고 `Add note here`를 누르면 현재 PDF 페이지 또는 문서의 현재
  읽기 위치에 독립 메모가 저장됩니다.
- 라이브러리 화면 검색줄의 `▧`(내 하이라이트·메모)를 누르면 **모든 문서**의
  하이라이트·메모를 한 화면에서 문서별로 모아 볼 수 있습니다. 검색창으로 내가
  쓴 인용문·메모 글자를 찾고, 색상 칩으로 걸러보고, `Go to`로 해당 문서를 열어
  바로 그 위치로 이동합니다. 며칠에 걸쳐 여러 문서에 쌓인 메모를 복습할 때
  유용합니다.
- 라이브러리 목록의 각 문서 줄에도 하이라이트·메모 개수(예: `12 hl · 3 notes`)가
  작게 표시되어, 어떤 문서를 많이 공부했는지 한눈에 보입니다.
- 주석은 Folio 데이터에 따로 저장되며 원본 PDF와 문서 파일은 수정하지 않습니다.
- 스캔 PDF와 이미지는 선택할 실제 텍스트가 없으므로 독립 메모만 사용할 수 있습니다.
- TXT·Markdown·HTML 문서에서 하이라이트나 독립 메모를 저장하면, 그 위치 바로
  위에 있는 소제목(`#`~`######`, HTML은 `h1`~`h6`)을 자동으로 찾아 위치 표시에
  함께 붙입니다(예: `43% · Section Two`). 문서 전체에 대한 메모뿐 아니라 특정
  단락·소제목에 딸린 메모인지도 목록에서 바로 구분할 수 있습니다. 소제목이
  없는 문서(TXT 등)나 PDF·CSV·이미지는 기존 방식(페이지·행·스크롤 %) 그대로
  표시됩니다.

### 형식별 도구

| 형식 | 위쪽 | 아래쪽 |
|---|---|---|
| PDF | `Outline` `Find` `Rotate` | 페이지 슬라이더 + `12 / 184` |
| Markdown | `Contents` `Find` `Source` | 없음 |
| HTML | `Read` `Run` `Source` + `Find` | Run일 때 `Preview issues` |
| 텍스트 | `Find` `Encoding` `Wrap` | 스크롤 위치 |
| CSV | `Find` `Columns` `Delimiter` `Encoding` | `Row 1,204 / 8,391` |
| 이미지 | `Rotate` `Info` | 확대 슬라이더 + `Fit` |

### 한글이 깨져 보일 때

텍스트·CSV 뷰어의 **Encoding** 에서 `CP949` 를 고르면 됩니다. Excel에서 저장한
한글 CSV가 대개 여기에 해당합니다. 고른 값은 그 문서에 저장됩니다.

## 4. HTML 문서의 세 가지 모드

| 모드 | 하는 일 |
|---|---|
| **Read** (기본) | 스크립트를 제거하고 글만 보여 줍니다. 가장 안전합니다 |
| **Run** | 스크립트를 격리된 샌드박스 안에서 실행합니다 |
| **Source** | 원문 코드를 그대로 봅니다 |

**Run은 문서마다 따로 켭니다.** 처음 켤 때 확인을 한 번 받습니다 —
`Scripts in this document will run in an isolated sandbox. It cannot read your
other documents, send data anywhere, or keep anything after you leave.`

ZIP 패키지(`.zip`)는 Run 전용입니다. 실행 중 문제가 생기면 아래쪽
`Preview issues` 에 목록으로 모입니다. 이 내용은 저장되지도, 동기화되지도
않습니다.

## 5. 보관과 해제 (Retention)

저장 공간을 위해, 오랫동안 열지 않은 문서의 **원본 사본만** 지웁니다.

- 제목·태그·읽은 위치·본문 검색은 **그대로 남습니다.**
- 텍스트·Markdown·HTML·CSV는 **절대 해제하지 않습니다.**
- 핀(Pin)을 찍은 문서는 시계가 멈춥니다.
- 처음 자동 해제가 일어날 때 한 번 물어봅니다. 그다음부터는 알림만 뜹니다.

해제된 문서를 열면 **Choose the original file** 화면이 나옵니다. 원본 파일을
고르면 해시를 대조해 다시 연결하고 읽던 위치로 돌아갑니다 — `Reconnected.`
다른 파일을 고르면 두 파일을 나란히 보여 주고 선택하게 합니다.

## 6. 설정(Settings)

| 구역 | 항목 |
|---|---|
| Display | `Text size` 6단계(6·8·10·12·14·17) · `Reset` · `Appearance` (System/Light/Dark) |
| Storage | `Retention` (7d·14d·30d·Never) · `Release expired now` · 사용량 |
| Backup | `Export backup` · `Restore from backup` |
| Sync | 기본 꺼짐. 켤 때 기기 이름을 먼저 묻습니다 |
| Journal | 기본 꺼짐. Daybook에 활동을 보냅니다. 선택 문구·메모 본문 포함 여부를 따로 정합니다 |
| Danger | `Delete all documents` |
| About | 빌드 번호 · `Licences` |

`Text size` 는 **앱 화면 글자**입니다. 문서 본문 글자는 뷰어에서 따로
조절합니다.

## 7. 삭제

- 문서 하나 삭제는 확인 없이 실행되고 **5초 동안 `Undo`** 가 뜹니다. 누르면
  사본·본문·읽은 위치가 한 번에 되돌아옵니다.
- 5초가 지나면 확정됩니다. Files에 있는 **원본 파일은 건드리지 않습니다.**
- Undo가 떠 있는 채로 앱을 닫으면 다음 실행에서 삭제가 확정됩니다.
- 전체 삭제(`Delete all documents`)는 확인 대화상자가 뜹니다.

## Daybook Journal 기록 복원

- **Add existing history**는 문서 added 날짜뿐 아니라 저장된 highlight/note의 createdAt·updatedAt도 가져옵니다. 가져온 주석 참조가 보존되어 이후 삭제도 같은 remote record를 정리할 수 있습니다.
- **Include selected text and note bodies**를 끄면 pending 및 새 record의 quote/note가 제외됩니다. **Remove content**는 선택 기간의 현재 projection만 정제합니다.
- 90일 파일 metadata activity는 Journal opt-in과 무관하게 로컬에 보관되고 JSON 백업/복원에 포함됩니다. **Clear captured activity**는 문서·주석을 건드리지 않고 이 원장만 지웁니다.

## 읽기 세션

문서를 열어 두고 5분 넘게 손을 떼었다가(idle) 다시 스크롤하거나 터치하면 새 읽기 세션이 시작되어 Daybook에 반영됩니다. 문서를 실제로 닫거나 다른 문서로 넘어갈 때만 세션이 완전히 종료됩니다.

Journal의 **Include selected text and note bodies**가 꺼져 있으면 읽기 세션의 문서 제목도 `Folio document`로 비식별화됩니다. 따라서 나중에 session backfill을 실행해도 실제 문서 제목이 원격 Journal로 전송되지 않습니다.

## Markdown 다이어그램·표·인용구, HTML Read

**Markdown**

- 코드 블록에 ```flowchart``` 를 쓰면 화면 안에서 순서도로 그려집니다(외부
  라이브러리 없이 folio 자체 렌더러). 지원하지 않는 문법이면 원본 코드가 그대로
  보입니다. 탭하면 확대해서 볼 수 있고, 사진 보기와 같은 손가락 확대·축소가
  됩니다.
- 넓은 표는 가로로 스크롤됩니다. 헤더 행은 스크롤해도 위에 고정됩니다.
- 인용구(`>`)는 내용에 따라 다르게 표시됩니다 — 출처, 전제지식, 다른 관점, 일반
  인용을 구분합니다.
- `[load-bearing]` `[supporting]` `[skippable]` 같은 태그는 작은 칩(chip)
  모양으로 바뀝니다.
- **Contents** 도구가 제목 수준(단계)을 들여쓰기로 보여 주고, 지금 읽는 위치를
  표시합니다.

**HTML — Read 모드**

- Read 모드가 문서 안의 `<style>`과 색·꾸밈을 이제 그대로 보여 줍니다(이전에는
  전부 지워지고 글자만 남았습니다). 인라인 SVG 그림, `<details>` 접기 상태도
  그대로 유지됩니다.
- 스크롤 위치 기억, 글자 크기(확대/축소) 6단계가 이제 HTML 문서에도 똑같이
  적용됩니다.
- 안전 장치는 그대로입니다 — 스크립트는 여전히 전부 제거되고, 네트워크로 나가는
  요청(이미지·글꼴·외부 CSS 등)은 전부 막힙니다.
